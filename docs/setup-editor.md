# Setupエディタの操作仕様

## ポイントを配置する

画像の空白をクリック／タップすると仮ポイントを表示し、Setupに追加済みのアイテムを選ぶポップオーバーを開く。選択した時点で確定する。仮ポイントをキャンセルしても保存データは変わらない。

アイテム側の「画像に配置」は1回の配置待ちに入る。配置後は通常操作へ戻る。同じアイテムを同じ画像の複数箇所に配置でき、候補に配置数を表示する。Setup全体の上限は128ポイント。

キーボードでは「ポイントを追加」で画像中央に仮配置し、アイテム選択後に矢印キーで位置を調整する。画像の読み込み完了前、読み込み失敗時、アイテム未追加時には新規配置を開始しない。

## ポイントを編集する

ポイントを選ぶと、その横にアイテム変更・移動・削除を表示する。アイテム変更はポイントIDと位置を維持する。位置はドラッグ、「移動」後の画像クリック／タップ、矢印キーで変更できる。矢印キーは表示上の1px、Shift併用では10px移動する。

5px未満のポインター移動はクリックとして扱う。ドラッグの終了時だけ保存し、終了後のクリックを追加として扱わない。ポインター操作の中断やEscapeでは仮移動を破棄する。タッチ操作のスクロール抑止はポイント上に限定する。

ポップオーバー表示中に画像の空白を押すと閉じるだけ。別ポイントを押すと選択を切り替える。Escapeは仮配置・選択メニュー・移動を先に解除し、次のEscapeで編集モーダルを閉じる。キーボードで操作を確定／キャンセルしたらポイントへフォーカスを戻す。

追加・変更・削除・移動完了をTanStack Formへ反映し、既存の下書き保存を使う。モーダルにも同じ保存状態を表示する。「完了」や閉じる操作で確定済み変更を保持する。

Undo／Redoはモーダルを開いている間の対象画像に限定し、最大100操作を保持する。ドラッグやキーの連続移動は1操作。Ctrl／Cmd+Z、Shift+Ctrl／Cmd+Z、Ctrl／Cmd+Yにも対応する。文字入力中はブラウザーのテキスト編集を優先する。取り消し結果も自動保存する。

## アイテムを追加する

候補表示はNuxt UIの`UInputMenu`のautocompleteモードを使い、矢印キーとEnterで選択できる。Escapeで閉じる。入力欄のEnterは投稿を送信しない。IME変換中は検索・追加を行わない。選択後は入力を空にしてフォーカスを維持する。

URLの貼り付けだけでは取得・追加を開始しない。「URLから追加」を選んだ時点で、最大4件同時に取得する。一度に32URLまで。取得状況と個別の再試行を表示し、同じCatalogItemの重複追加を防ぐ。Setupの上限32アイテムに達したら、追加できなかったURLを再試行できる状態で保持する。

名前検索は300msのデバウンス。入力変更時に古い検索・ページ取得を無効化し、古い候補を選べないようにする。通信失敗では同じ検索／ページを再試行できる。

検索とURL処理はcomposeページの寿命で保持する。空状態からの最初の追加、モバイルタブ切り替え、画面幅変更で処理を失わない。下書き・アカウント切り替えと離脱時に処理を終了し、遅延応答を別の下書きに追加しない。

## 実装と受け入れ条件

- UIは`UModal`、`UPopover`、`UCommandPalette`、`UInputMenu`。ドラッグ・画像領域・履歴はVueUse。確定データはフォームを参照し、Proxyを直接`structuredClone`しない。
- 2個目以降の追加、変更、削除、Undo／Redo、保存・復元で表示とデータが一致する。
- リサイズ・画像端・縦長画像・スマホでもポイント座標とポップオーバーが画像に追従する。
- ポインター中断・Escape・フォーカス復帰・IME・検索応答の順序逆転・複数URLの部分失敗を確認する。
- 画像・アイテムの削除ではポイント編集を終了する。下書き・アカウントの切り替えでは検索とURL処理も終了し、旧データの履歴や遅延応答を適用しない。
